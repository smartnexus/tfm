# <u>TFM</u>: Sistema para la comunicación síncrona punto a multipunto: aplicación a una orquesta sinfónica distribuida
Para equilibrar el compromiso entre los conocimientos de los participantes y las expectativas que estos aguardan del servicio, se van a elaborar un conjunto de pruebas que tengan una característica principal: presentar cada simulación a través de una pregunta concisa y un conjunto de respuestas conocidas (tomadas a partir de los valores asociados a las figuras de mérito).

Estas simulaciones incluirán las respuestas necesarias para poder evaluar cada figura de mérito en el mayor rango verosímil. De tal forma que, las puntuaciones de cada una de las respuestas proporcionen la información necesaria para asignar los valores y errores adecuados pertenecientes a las figuras de mérito de cada indicador (requisito paramétrico). 

En resumen, cada prueba debe poseer dos caras, una suficientemente específica para la correcta recolección de valores necesarios y otra en la que el nivel de abstracción alcanzado permita que los participantes puedan realizar una evaluación que no requiera un alto nivel de conocimientos.

Por ejemplo: si se desea evaluar la figura de mérito asociada al tiempo de respuesta de un servicio ante un comando efectuado por un cliente, la prueba consistirá en hacer que el cliente accione el comando varias veces, de tal forma que en cada una se muestre la simulación de la respuesta con un tiempo diferente. Una vez acabada la prueba el cliente concluirá cual o cuales de las simulaciones están dentro de su margen admisible.

Si las pruebas se diseñan de manera específica y teniendo en cuenta todos los aspectos que influyen (similar a un proceso de calibración), se recolectarán los suficientes datos para cada una de las figuras de mérito.
