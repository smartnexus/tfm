# Testbench
Mediante este banco de pruebas se tiene como objetivo cuantificar los valores correspondientes a las figuras de mérito de los requisitos del sistema de comunicaciones.

Mediante un conjunto de pruebas definidas, se pretende obtener como resultado un intervalo realista fruto de las respuestas de cada uno de los participantes.

Por último, con el fin de garantizar la veracidad de resultados es deseable que los participantes tengan una mínima formación musical.

**Izquierda sin retraso, derecha con retraso.**

## Participantes necesarios
| Código de la prueba | número |
|---|---|
| NASVP-01 | 1 |
| NASVP-02 | 1 |
| NASVR-01 | 2 |
| NASVR-02 | 2 |
| NESCS-01 | 1 |
| NESCS-02 | 2 |
